# FlowSight — India Road Lab 🚦

**Explainable traffic analytics for exploring road scenarios with machine learning.**

FlowSight combines OpenStreetMap road context with a React dashboard and a Flask analytics API. Users can choose a city area, look up mapped roads when the public map service is available, edit traffic inputs, and inspect similar simulated observations, traffic groups, decision-tree rules and linear-model contributions.

> **Important:** road geometry comes from OpenStreetMap when available; the 2,400 traffic observations are generated by the project. The analytics are educational demonstrations—not live congestion measurements, actual journey-time forecasts, or evidence of the causal effect of lane closures.

## Features

- Interactive OpenStreetMap view with city shortcuts and selectable returned road geometry.
- Editable traffic scenario: hour, vehicle volume, speed, rainfall, incidents and open lanes.
- K-Means traffic segments, KNN nearest-record retrieval, a decision-tree group explainer and linear regression contributions.
- Lane-closure scenario comparison, comparable-record table and JSON export.
- Input validation and a manual-analysis fallback when the public road lookup is unavailable.
- Backend and frontend test suites plus GitHub Actions CI.

## Stack

- **Frontend:** React, Vite, Leaflet, Recharts
- **Backend:** Python, Flask
- **ML/data:** scikit-learn, pandas, NumPy, joblib
- **Map data:** OpenStreetMap contributors via the public Overpass API

## Run locally

Use Python 3.10+ and a recent Node.js version.

### 1. Install Python dependencies and train the models

From the repository root:

```bash
python -m venv .venv
```

Windows PowerShell:

```powershell
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
python backend\train_models.py
```

### 2. Install and build the frontend

Open a second terminal:

```powershell
cd frontend
npm install
npm run build
```

### 3. Start the Flask app

From the repository root, with the Python environment active:

```powershell
python backend\app.py
```

Open [http://127.0.0.1:5000](http://127.0.0.1:5000). For frontend development, run `npm run dev` from `frontend`; Vite proxies `/api` requests to Flask at `127.0.0.1:5000`.

## API endpoints

| Method | Endpoint | Purpose |
|---|---|---|
| GET | `/api/health` | Check that trained model artifacts are available |
| GET | `/api/dashboard` | Return training summary |
| POST | `/api/analyze` | Analyze a traffic scenario and reference |
| POST | `/api/similar` | Retrieve nearest observations |
| POST | `/api/map/roads` | Look up nearby mapped roads through Overpass |

## Model and data limitations

- The model dataset is simulated and seeded for reproducibility; it does not represent measured traffic in any particular city.
- K-Means labels are descriptive clusters. The decision tree is a simplified explainer and may disagree with the most common nearest-neighbour group.
- Linear contributions describe associations in the fitted synthetic model, not causality.
- OpenStreetMap provides road geometry and mapped tags, not live traffic conditions. Lane tags may be absent, outdated or ambiguous.
- The public Overpass service can time out or rate-limit requests; the app should show a manual-scenario fallback rather than inventing roads.
- Do not use this prototype for navigation, emergency response or real traffic-management decisions.
